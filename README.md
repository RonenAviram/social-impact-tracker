# קווים אדומים — מערכת מדידת אימפקט ברשתות חברתיות

## Demo
> **[טופס הזנת נתונים](https://ronenaviram.github.io/social-impact-tracker/form.html)** | **[דשבורד](https://ronenaviram.github.io/social-impact-tracker/dashboard.html)**

## מה זה
מערכת של ארגון "קווים אדומים" — השותפות למניעת אלימות בזוגיות — שמודדת את האימפקט של תכנים מתואמים ברשתות חברתיות ובמדיה.

**מצב נוכחי:** פרוטוטייפ UI מוכן (נתונים מסומלצים). הצעת מחיר אושרה ע"י הלקוחה. בבנייה — backend אמיתי.

### עיקרון מנחה: דמו = מוצר
הדמו הוא לא מוקאפ נפרד — הוא ה-blueprint של המוצר עצמו. מעבר לפרודקשן = החלפת data מדומה ב-data אמיתי + הוספת לוגיקה, לא שכתוב UI. כל פיצ'ר חייב להיות נתמך בבקאנד. אפס דרישות טכניות מצד הארגון.

### 1. טופס הזנת נתונים (`form.html`)
- ויזארד דו-שלבי: בחירת פלטפורמות → הזנת נתונים לכל פלטפורמה
- תמיכה בהזנת מספר סוגי תוכן לכל פלטפורמה
- 11 פלטפורמות: פייסבוק, אינסטגרם, טיקטוק, X, לינקדאין, ספוטיפיי, יוטיוב, רשימת תפוצה, עיתון מודפס, אתר אינטרנט, וואטסאפ
- מטריקות דינמיות לפי פלטפורמה וסוג תוכן
- בורר נושא שבועי, קישור חובה, שדה תאריך העלאה

### 2. דשבורד (`dashboard.html`)
- משאבים משותפים: קישור משותף + דף מסרים
- כרטיסי מטריקות: חשיפות, Engagement, תכנים, משתתפים פעילים
- יעדים: התקדמות מול יעדים מוגדרים
- גרפים: עוגה (לפי פלטפורמה), קו (חשיפות מצטברות), עמודות (Engagement), העלאות לאורך זמן
- ארכיון קישורים: רשימת כל הקישורים שהוזנו, עם סינון — לשיתוף תכנים של אחרים
- פילטר גלובלי: פלטפורמה + ארגון
- לוח מובילים (החלטה פתוחה — ייתכן שיוסר)
- פאנל מנהל: טבלת נתונים גולמיים

## תוכנית פרודקשן

### Backend
- **Supabase free tier** — DB + API, אפס עלות שוטפת
- **GitHub Pages** — hosting (כבר עובד)
- טבלה אחת: date, person, org, platform, type, metrics (JSON), link
- Form כותב ל-DB, Dashboard קורא ממנו

### ממשק אדמין
- פתיחה/סגירה של נושא שבועי (שם + תאריכים)
- ניהול רשימת שמות וארגונים (הוספה/הסרה)
- עריכה/מחיקה של הזנות שגויות
- עיקרון מנחה: אחרי ההשקה הכל מנוהל ע"י האדמין, בלי תלות במפתח

### זיהוי משתמש
- dropdown סגור של שם+ארגון (לא לוגין)
- אפשרות לאדמין להוסיף שמות

### שאלות אפיון פתוחות
- לוח מובילים: להשאיר או להוריד?
- היסטוריה של נושאים קודמים בדשבורד, או דף נקי כל שבוע?
